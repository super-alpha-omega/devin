BYBIT24 — JavaScript (Node.js) версия с самовосстановлением
============================================================

Это полный перенос бота BYBIT24 (24 стратегии / 8 групп + памп и мульти-памп, риск-менеджмент,
частичный тейк, безубыток, перевод 70% прибыли, локальный ИИ-фильтр, веб-панель) с Python на JavaScript.

ЗАПУСК (Windows)
1. Распакуйте ZIP целиком в любую папку.
2. Запустите START.bat — откроется локальная панель в браузере (http://127.0.0.1:63724).
   Node.js встроен в папку runtime, устанавливать ничего не нужно.
3. В панели «Подключение и настройки»: режим REAL или DEMO, API Key + Secret, «Сохранить настройки».
4. Нажмите «Старт». STOP.bat / кнопка «Стоп» — остановка торговли (позиции и ордера не закрываются).
CHECK.bat — самопроверка (автотесты, без запросов к бирже).

САМОВОССТАНОВЛЕНИЕ (без участия человека)
- Супервизор (supervisor.js) держит бота запущенным: при падении процесса — перезапуск
  через 2…60 с; если процесс «завис» (нет сигнала 90 с) — принудительный перезапуск.
- Внутри бота: сторож торгового цикла (перезапуск при зависании > 5 мин), автоматический
  перезапуск торгового цикла при неожиданном завершении, полный перезапуск ядра после 20
  ошибок подряд. Журнал и позиции при этом сохраняются.
- Нет связи с биржей / таймауты / лимиты запросов — повтор с нарастающей паузой (3…60 с),
  после восстановления поиск сделок включается сам (раньше требовалась кнопка «Продолжить»).
- Ошибка при старте (нет сети, неверное время, ключ, режим счёта) — бесконечные повторы с паузой до 5 мин.
- Любая пауза входов («ВХОДЫ ПРИОСТАНОВЛЕНЫ») снимается автоматически: бот сам делает сверку
  Bybit и включает входы (повтор 30 с … 15 мин). Дневной лимит убытка снимается в новый день (Киев).
  Ошибка авторизации ключа — проверка каждые 5+ мин.
- Неопределённые ордера: вход/закрытие/частичный тейк, не найденные на бирже 2 минуты, считаются
  не дошедшими и закрываются в журнале; отклонённое закрытие повторяется (reduce-only);
  зависший вход отменяется через 5 мин. Вслепую ордера не повторяются никогда.
- Проблемная позиция изолируется отдельно («изоляция»), остальная торговля продолжается.
  Если позиция не сверяется 24 часа — бот её отсоединяет: TP/SL на бирже остаются, инструмент
  блокируется, риск остаётся зарезервированным.
- Позиция, уменьшенная вручную на бирже, принимается по факту.
- Пауза группы стратегий после убытка > R снимается через 24 ч (настройка group_halt_cooldown_hours, 0 = вручную).
- Журнал (data/portfolio_*.json) пишется атомарно с резервной копией; повреждённый файл восстанавливается из копии.
- Критическая ошибка JS — запись в logs/crash.log и чистый перезапуск процесса.
- Автозапуск после перезагрузки Windows: галочка «Продолжать после аварийного перезапуска»
  (включена по умолчанию). После ручного «Стоп» бот сам не стартует.

ФАЙЛЫ
supervisor.js — сторож процесса;  src/ — код бота;  public/desktop_panel.html — панель;
data/ — настройки и журнал;  logs/ — bot.log, supervisor.log, crash.log;  .env — ключи (не передавайте никому).

ВАЖНО
- Старый Python-журнал (portfolio.sqlite3) не переносится: если у старого бота есть открытые
  позиции, сначала закройте их или дождитесь закрытия, затем запускайте эту версию. Не запускайте
  обе версии на одном счёте одновременно.
- Сначала проверьте на DEMO. Прибыль не гарантируется.
